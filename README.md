# ВОКСА (VoiceTask)

**ВОКСА** — веб-приложение для планирования задач, встреч и событий с календарём, текстовым помощником и голосовым вводом на русском языке.

## Возможности

- Просмотр календаря по дням, неделям, месяцам и годам.
- Создание, изменение, поиск и удаление задач, встреч и событий.
- Повторяющиеся записи, отметка выполнения задач и отмена последних изменений.
- Текстовые команды: простые выполняются локально, сложные интерпретируются с помощью ИИ.
- Голосовой ввод с локальным распознаванием речи; перед отправкой распознанный текст можно исправить.
- Напоминания в интерфейсе и дополнительные фоновые уведомления Windows.
- Настройки внешнего вида, резервное копирование и восстановление календаря в JSON.

## Быстрый запуск на Windows

В **предоставленном архиве** уже есть локальный Node.js (`.tools/node.exe`), установленные зависимости (`node_modules`) и скрипты запуска.

1. Распакуйте архив в отдельную папку, например `C:\Projects\VoiceTask`.
2. Откройте папку **`VoiceTask`**, в которой находятся `START.cmd` и `package.json`.
3. Дважды щёлкните по **`START.cmd`**. Скрипт проверит локальные компоненты распознавания речи, запустит сервер и откроет браузер.
4. Если браузер не открылся автоматически, перейдите по адресу:

   **http://localhost:5173/VoiceTask/**

5. Чтобы остановить сервер, запустите **`STOP.cmd`**.

> При первом запуске может понадобиться интернет для загрузки недостающих речевых компонентов. Не удаляйте из распакованной папки `.tools` и `node_modules`. Запуск рассчитан на Windows, а речевые компоненты и фоновые системные уведомления используют Windows-специфичные инструменты.

## Запуск для разработки (через терминал)

Для этого способа нужны **Node.js и npm** (рекомендуется актуальная LTS-версия Node.js, совместимая с Vite 6).

В терминале, находясь в папке `VoiceTask`, выполните:

```bash
npm ci
npm run dev
```

Затем откройте **http://localhost:5173/VoiceTask/**. Если порт занят, Vite может показать другой порт в терминале.

Изменения в исходном коде отображаются в браузере автоматически. Чтобы завершить работу сервера, нажмите `Ctrl+C` в терминале.

**Важно:** `npm run dev` запускает веб-приложение и его локальные API, но сам по себе не устанавливает модель для распознавания речи. В Windows её можно подготовить отдельно:

```bash
node scripts/setup-speech.mjs
```

Для исходной сборки распознавания требуется Windows: используется `whisper-cli.exe`. На других ОС интерфейс и ручная работа могут запускаться, но голосовой ввод и фоновые уведомления Windows не будут работать без адаптации.

## Настройка искусственного интеллекта

Подключение к OpenRouter **необязательно** для обычной работы календаря. Локальные команды работают и без ключа; для сложных запросов нужен доступ к интернету и ключ OpenRouter.

1. Откройте файл `.env` в корне проекта. Если его нет, создайте копию `.env.example` с именем `.env`.
2. Укажите свой ключ:

   ```dotenv
   OPENROUTER_API_KEY=ваш_ключ_OpenRouter
   OPENROUTER_MODEL=nvidia/nemotron-3.5-super-vl:free
   ```

3. Сохраните файл. Если сервер уже запущен, при необходимости перезапустите его.

Ключ считывается локальным сервером и **не должен** попадать в код браузера, Git или публичный архив. Перед передачей проекта третьим лицам удалите действующие секреты из `.env`, оставив `.env.example` без ключа.

## Как пользоваться

После запуска откройте календарь. Можно выбрать дату, создать задачу, встречу или событие и указать параметры записи. В разделе чата доступны текстовые команды, например: «Создай встречу завтра в 15:00» или «Найди задачи на эту неделю».

Для голосового ввода разрешите браузеру использование микрофона, нажмите кнопку записи, произнесите команду и остановите запись. Распознанный текст появится в чате: его можно отредактировать и отправить. Аудио распознаётся локально, без передачи аудиозаписи в OpenRouter.

Для фоновых системных напоминаний откройте **Настройки → Уведомления → Фоновые напоминания Windows**. При первом включении могут понадобиться интернет, разрешения Windows и установка дополнительных компонентов. Компьютер должен быть включён.

## Архитектура и технологии

| Компонент | Технологии и назначение |
| --- | --- |
| Пользовательский интерфейс | React 19, TypeScript 5.8, CSS, lucide-react |
| Сборка и локальный сервер | Vite 6, Node.js |
| Локальные данные | `localStorage` браузера |
| Обработка простых команд | Локальный интерпретатор команд на TypeScript |
| Сложные команды | OpenRouter, модель `nvidia/nemotron-3.5-super-vl:free` |
| Распознавание речи | `whisper.cpp` 1.8.3, Whisper small q5_1, Silero VAD |
| Озвучивание ответов | Web Speech Synthesis |
| Фоновые уведомления | Локальный API и компонент C# для Windows |

Структура основных каталогов:

```text
VoiceTask/
├── src/                  # Интерфейс и клиентская логика
│   ├── calendar/         # Представления календаря
│   ├── chat/             # Диалог с помощником
│   ├── storage/          # Хранение данных, резервные копии
│   ├── reminders/        # Настройка напоминаний
│   └── profile/          # Профиль пользователя
├── server/               # Локальные API: ИИ, речь, напоминания
├── scripts/              # Подготовка компонентов и тесты
├── tests/                # Автоматические проверки
├── public/               # Статические файлы и исходный CSV
├── .env.example          # Пример конфигурации ИИ
├── START.cmd             # Запуск на Windows
├── STOP.cmd              # Остановка на Windows
└── package.json          # Зависимости и команды
```

Данные календаря и настройки сохраняются **в браузере, а не в облачной базе данных**. Поэтому при смене браузера, адреса приложения или очистке данных сайта записи могут быть недоступны. Для переноса данных используйте экспорт и импорт JSON в настройках календаря.

## Проверка проекта и сборка

```bash
npm run typecheck    # Проверка типов TypeScript
npm test             # Автоматические тесты логики
npm run build        # Сборка проекта в папку dist/
```

Для запуска собранной версии локально:

```bash
npm run preview
```

Адрес предварительного просмотра указан в терминале (обычно `http://localhost:4173/VoiceTask/`). Локальные API подключаются плагинами Vite и при таком запуске тоже доступны; **простое размещение папки `dist` на статическом хостинге не обеспечивает серверные функции** распознавания речи, ИИ и Windows-уведомлений.

## Принятые решения при разработке

- **Локальное хранение вместо обязательного сервера с базой данных.** Упрощает запуск и позволяет работать с календарём без регистрации и постоянного подключения к интернету.
- **Гибридная обработка команд.** Простые команды выполняются по правилам без сетевого запроса, а сложные направляются модели. Это уменьшает зависимость от ИИ и позволяет пользоваться основной функциональностью без ключа.
- **Проверка ответов модели до изменения календаря.** ИИ возвращает структурированную команду в JSON; приложение проверяет её и выполняет действие локально. Ошибочный ответ не должен непосредственно менять записи.
- **Локальное распознавание речи.** Аудио обрабатывается на компьютере пользователя; распознанный текст сначала можно проверить и исправить.
- **Разделение функций по модулям.** Календарь, чат, хранение, уведомления и профиль вынесены в отдельные папки, чтобы код было проще тестировать и развивать.
- **Восстановление данных.** Предусмотрены экспорт и импорт записей, а также отмена последних изменений для снижения риска случайной потери информации.

## Что можно улучшить при наличии дополнительного времени

1. **Синхронизация между устройствами.** Добавить необязательную авторизацию, серверную базу данных и безопасную синхронизацию, сохранив возможность локальной работы.
2. **Полноценная кроссплатформенность.** Адаптировать распознавание речи и уведомления для macOS/Linux и мобильных устройств, не привязывая их к Windows.
3. **Интеграции с календарями.** Реализовать импорт/экспорт `.ics` и синхронизацию с внешними календарными сервисами.
4. **Улучшение качества голосового помощника.** Расширить набор локально распознаваемых формулировок и тестов для неоднозначных запросов, сложных дат и повторений.
5. **Удобство развёртывания.** Сделать отдельный сервер для API и автоматизированную установку зависимостей, чтобы приложение можно было надёжно размещать не только на компьютере разработчика.

## Если возникли проблемы

- **Не открывается сайт:** проверьте, запущен ли `START.cmd`, и попробуйте открыть адрес вручную. Убедитесь, что порт `5173` не занят другим приложением.
- **Ошибка при запуске `START.cmd`:** убедитесь, что архив распакован полностью и папки `.tools` и `node_modules` на месте. Диагностика сервера: `.tools/local-server.log` и `.tools/local-server-error.log`.
- **ИИ не отвечает:** проверьте `OPENROUTER_API_KEY`, подключение к интернету и доступность OpenRouter. Без ИИ календарём по-прежнему можно пользоваться вручную.
- **Микрофон не работает:** проверьте разрешение на микрофон и наличие файлов в `.tools/speech`; при необходимости запустите `node scripts/setup-speech.mjs` в Windows.
- **Исчезли записи:** проверьте, что используете тот же браузер и адрес сайта; восстановите сохранённую резервную копию JSON, если она есть.
